An AI analyst drafts sections of a consulting synthesis memo from a fictional engagement's source library (a health system weighing an ambulatory surgery center). One file in the library belongs to a different client. 30 requests, 3 runs each, graded with golive-gate: rules check citations, figures, client walls, gaps and conflicts; a Claude judge checks that each claim says only what its sources say. The gate decides whether the workflow graduates from Assisted (an analyst writes) to First-pass (the agent drafts, an analyst reviews).
